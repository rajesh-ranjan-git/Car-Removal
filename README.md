## Project Overview

Car-Removal is a static marketing landing page for a car removal/repair service. It presents company information, services, and a call-to-action layout styled with Bootstrap and custom CSS.

## Features

- **Business Landing Layout:** Header, services, and call-to-action sections.
- **Bootstrap Components:** Responsive grid and UI components from Bootstrap.
- **Icon Support:** Font Awesome icons used throughout the page.

## Tech Stack

- **Frontend:** HTML5, CSS3, Bootstrap
- **Icons:** Font Awesome

## Folder Structure

```bash
Car-Removal/
├── css/              # Stylesheets (Bootstrap + custom)
├── font-awesome/      # Font Awesome icon library
├── js/                # JavaScript used by Bootstrap/UI components
├── media/             # Media assets used across the page
├── index.html         # Main landing page markup
└── style.css          # Custom page styling
```

## Installation Guide

### Prerequisites

- A modern web browser
- (Optional) A local static server such as VS Code's "Live Server" extension

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/rajesh-ranjan-git/Car-Removal.git
   cd Car-Removal
   ```

2. Open `index.html` directly in your browser, or serve the folder with a local static server:

   ```bash
   npx serve .
   ```

## Usage Instructions

1. Open the page in your browser to view the car removal service landing page.
2. Browse the services and company information sections.
